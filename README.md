# Checkout React

Projeto individual desenvolvido para o Módulo 2, semana 7, da formação Front-End React do SCTEC.

## objetivo

Construir uma interface de finalização de compras com carrinho fixo e pagamento simulado no navegador.

A aplicação terá quatro páginas: Carrinho, pagamento, sucesso e falha. Serão utilizados apenas dados fictícios, sem integração com serviços de pagamentos e sem persistência dos dados do cartão.

## Estado atual

- Projeto React criado com Vite e JavaScript.
- Dependências instaladas.
- Página inicial executada no navegador.
- Repositório GitHub configurado com main e develop.
- Planejamento em andamento.

As funcionalidades do checkout ainda serão implementadas.

## Como executar

Ambiente utilizado: Node.js 24,15.0 e npm 11.12.1.

No terminal:

git clone
https://github.com/alexandredevsc/checkout-react.git
cd checkout-react
npm install
npm run dev

Abra no navegador o endereço informado pelo Vite.
